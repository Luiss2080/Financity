# GAME DESIGN DOCUMENT (GDD)

**Concepto**: El jugador inicia con 18 años, Bs 1.500 y Bs 0 de ingresos. El objetivo es alcanzar la estabilidad financiera.

**Mecánicas Principales**:
- UI basada en Cards y Eventos (sin mundo 3D).
- Mapa sencillo interactivo (Casa, Trabajo, Banco, Universidad, Tienda).
- Eventos aleatorios (Ej. "Tu celular se rompió: Reparar Bs 500 / Comprar Bs 3.800").
- Minijuegos con Phaser (para conceptos como interés compuesto).
