# PROJECT SPEC

**Visión**: FinanCity es un juego educativo de simulación financiera para enseñar ahorro, presupuesto, créditos e inversiones mediante decisiones, sin clases aburridas.

**Alcance (9 Fases)**:
1. MVP (Landing, Login, Perfil, Presupuesto, Ahorro)
2. Banco (Préstamos, Deudas)
3. Educación (Cursos, Empleos)
4. Emprendimiento
5. Inversiones
6. Gamificación (Desafíos, Quiz, Ranking)
7. PWA / Offline
8. Desktop (Electron)
9. QA Final
